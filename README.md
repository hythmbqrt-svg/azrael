# عزرائيل

بوت Facebook Messenger لإدارة المجموعات، مع أوامر عربية ولوحة تحكم.

## التشغيل

1. ثبّت الاعتماديات: pnpm install
2. شغّل البوت: pnpm start

## ملاحظات أمنية

- ملف جلسة Facebook لا يتم رفعه إلى GitHub.
- ملفات السجلات والبيانات التشغيلية مستبعدة من المستودع.
- استخدم متغيرات البيئة للمفاتيح الحساسة.
